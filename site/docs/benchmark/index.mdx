## 分数如何产生

1. Push CI 保留离线硬门禁（`moon run ci/eval/locomo`）。
2. 发版流水线在 **Publish mooncakes / tag / GitHub Release** 后结束（不再跑 LoCoMo archive）。
3. 发版后在本地跑三档并提交 `benchmarks/locomo/results/<version>.json`（见下方）。
4. 本页随 `main` 的 Pages 部署重建。

## 本地命令

```bash
# 离线档（进 push CI）
moon run ci/eval/locomo --target native

# api / live 单档
moon run ci/eval/locomo --target native -- --embedder api   # MOOMEM_EMBED_* / QWEN_*
moon run ci/eval/locomo --target native -- --live           # DEEPSEEK_*，全量 100 条

# 发版后本地归档三档并 commit + push（NEW_VERSION = 已发布版本）
set -a && source .env && set +a
NEW_VERSION=0.4.0 bash scripts/ci/run-locomo-benchmark-archive.sh
```

api 档环境映射：`QWEN_*` → `MOOMEM_EMBED_*`。live 档只读 `DEEPSEEK_*`。结果 JSON 永不写入 API Key。
